## 🚀 Flagship project — Finanza IA

**Finanza IA** is my current active MVP: a personal-finance platform that turns everyday financial activity into structured, useful information through WhatsApp and a web application.

The repository is currently **private while the product is under active development**, but the architecture includes:

- **FastAPI** backend APIs
- **PostgreSQL** for persistent financial data
- **Next.js + TypeScript** web dashboard
- **n8n** workflow automation
- **WhatsApp Cloud API** conversational interface
- **Docker** for reproducible environments and deployment
- **AI / LLM workflows** for natural-language financial interactions

The goal is to build a real product, validate it with users, measure outcomes and continuously improve it.
